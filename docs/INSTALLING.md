# Installing Rudrabha Mukherjee's Design Helper

These notes are for people who want the app on their home screen or start menu. You do not have to install it. Opening the web address, or saving the single HTML file and opening that file, both still work.

**Live address:** https://rudrabha-design-helper.pages.dev

## What installing does

Installing puts a shortcut beside your other apps. The app can then open in its own window, without the browser chrome, and can keep working when you have no internet. Your work still lives in this browser under this address. Installing does not move your work to a company server. It does not create an account.

## Android

1. Open the live address in Chrome, Edge, Samsung Internet or Firefox.
2. Use the browser menu and choose **Install app**, **Add to Home screen**, or the install icon in the address bar.
3. Confirm. The app appears on your home screen with its own icon.

It opens on its own. You can switch the phone to aeroplane mode and keep using work you already have on the device.

## iPhone and iPad

Safari does not show an install prompt. You choose it yourself:

1. Open the live address in Safari.
2. Tap **Share**, then **Add to Home Screen**.
3. Confirm the name and add it.

Open it from the home screen so it runs as its own app (standalone), not as a tab inside Safari.

### Storage on Apple devices — please read this

Apple’s WebKit may delete script-writable storage (including `localStorage`, where this app keeps your work) for sites you have not returned to for **seven days** of Safari use. See [Tracking Prevention in WebKit](https://webkit.org/tracking-prevention/) and [Updates to Storage Policy](https://webkit.org/blog/14403/updates-to-storage-policy/).

A **Home Screen** web app that opens in standalone or fullscreen mode is **exempt** from that seven-day deletion for its own domain. A page you only visit inside Safari is not. Prefer the home-screen copy for anything you care about, and use **Move or back up my work** to keep a file copy.

The installed copy and Safari do **not** necessarily share the same stored work. If you install and the app looks empty, use **Bring my work here** with a file you saved from Safari (or from another device).

## Windows

Open the live address in Chrome or Edge. Use the install icon in the address bar, or the browser menu item to install the app. It appears in the Start menu like other applications.

## macOS

Open the live address in Chrome or Edge and install from the address bar or browser menu. On recent macOS versions, Safari can also add a web app to the Dock; prefer standalone so storage is treated like a home-screen app.

## Ubuntu and other Linux

Chrome, Chromium and Edge can install the app and write a desktop entry. Firefox will keep working as an ordinary web page; it does not install web apps in the same way, and that is fine.

## Updates

When a newer version is ready, the app shows a quiet banner and asks before changing anything. Nothing updates underneath you mid-session. You can check yourself, or switch the automatic check off, in **Settings → Updates**. Your browser may still look at the worker file on its own; that cannot be switched off from inside a web page.

## Uninstalling

Remove the app from your home screen, Start menu or applications list in the usual way for your device. Clearing the site’s data in the browser also removes your work for that address — save a file first if you need it.

## The single-file copy

You can still save the app as one HTML file from inside it and open that file with no install and no updates. That copy never checks for a new version.
